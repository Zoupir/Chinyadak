# Site Auditor

افزونه ممیزی جامع Yadak Store برای تشخیص ناسازگاری بین سورس، API، تنظیمات، UI و رفتار واقعی مرورگر.

## خروجی‌ها
- تعریف‌های تکراری Route و تداخل mount
- فراخوانی‌های UI به APIهای بدون Route واضح
- TODO/FIXME و catchهای خالی در کد اجرایی
- وضعیت اتصال Extension Platform
- خطاهای runtime مرورگر و unhandled rejection
- درخواست‌های HTTP ناموفق
- تصاویر خراب، IDهای تکراری و بیرون‌زدگی افقی صفحه
- گزارش JSON و گزارش متنی برای تحلیل بعدی

## مدل امنیتی
خود افزونه فقط در مرورگر اجرا می‌شود. اسکن سورس از طریق endpoint فقط‌خواندنی Core در `/api/audit/site-audit` انجام می‌شود و فقط برای ادمین قابل استفاده است. افزونه هیچ فایل، دیتابیس یا تنظیمی را تغییر نمی‌دهد.
